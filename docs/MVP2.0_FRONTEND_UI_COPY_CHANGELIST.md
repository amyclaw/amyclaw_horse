# MVP 2.0 前端页面 UI 与文案更改清单

开发计划**已包含**前端页面的 UI 与提示/文案更改，对应 **PRD 阶段 2：个人助理 UI 与文案**。以下为按当前实现整理的**具体更改项**，便于开发与验收。

---

## 一、开发计划中的覆盖范围（PRD 第五章、阶段 2）

- **整体风格**：从拜年/节日主题改为**通用个人助理**风格（简洁、专业、可长期使用）。
- **首屏与引导**：首屏强调「您的个人助理」「为您服务」；在进入主对话前先完成**口令鉴权**（独立鉴权页/秘密框）。
- **UI 提示词与文案**：所有面向用户的提示、占位符、按钮文案统一为「个人助理」语境；避免「马厩」「马主」「拜年」等 MVP 1.0 表述（除非保留为可选主题）。

---

## 三、与流程的衔接

- **鉴权在前、对话在后**：首屏或弹层先出现「输入口令」秘密框及上述鉴权相关文案；鉴权成功后再进入主对话区域，此时状态与输入框等使用「已连接 / 与助理对话」类文案。
- **Guest 入口**（阶段 3）：若提供「访客通道」入口，需增加「以访客身份使用」的入口文案及 Guest 口令输入框（同样使用秘密框），与主人鉴权区分开。

---

## 四、汇总

- **开发计划已包含**上述前端 UI 与文案更改，对应 **PRD 第五章「界面与体验」** 与 **阶段 2「个人助理 UI 与文案」**。
- 具体改动点包括：**页面标题与 meta、页头标题与副标题、对话卡片内所有状态与占位符、鉴权页/秘密框文案、创建链接卡片标题与分享文案**；并**去除或替换**「马厩」「马主」「拜年」等表述，统一为「个人助理」语境。
- 实现时可按本文档逐项替换或新增，验收时对照「用户感知为专为自己服务的个人 AI 助理」即可。
